# D-0204: Frozen citation context

Assemble context over an immutable selected as-of view and revalidate supplied
bytes against its revision-bound source claim. Public citation and resolved
passage values are not themselves verification. Bound aggregate input before
hashing, and report missing and omitted evidence explicitly. Dissent and relation
claims remain in the selected view without inferred truth. This pure boundary
does not establish authorization, custody, source availability, or policy.
