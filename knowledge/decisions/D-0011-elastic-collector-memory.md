# Elastic collector memory

Use the lowest finite ancestor cgroup memory threshold for the automatic
hot ring size. A verified quarter-round-up formula reserves headroom before
computing the ring's share. Each pressure decision uses current usage and
capacity from the same cgroup.

Resource return applies only to optional compressed history. Unflushed
metrics have a separate queue and Spindle custody must pass the normal
flush and watermark checks. Pressure causes no separate deletion policy.
Lean and extracted Rust contracts check the arithmetic and idle-capacity
rules. Linux observations, allocator behavior, and durability are covered
at separate boundaries.
