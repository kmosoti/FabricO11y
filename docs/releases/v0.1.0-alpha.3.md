# FabricO11y v0.1.0-alpha.3

`v0.1.0-alpha.3` expands FabricO11y's zero-UI observability distribution and
library ecosystem while preserving strict loopback custody, `/data` non-tmpfs
storage discipline, and Rust `1.100.0` reproducibility.

## Highlights

- **Single-branch `main` + `CODEOWNERS` workflow:** Retired `main-human-gate.yml`
  and the separate `develop` promotion branch in favor of `.github/CODEOWNERS`
  (`* @kmosoti`) and stacked Jujutsu (`jj`) PRs targeting `main`.
- **Zero-UI `fabric-client` crate:** Added `fabric-client` to the workspace with
  null-safe `fabric.cli.v1` JSON schemas, concurrent `FabricClient` CLI polling,
  and `FabricQueryClient` enforcing `FABRIC_CREDENTIAL_FILE`-only reader auth,
  `FABRIC_CREDENTIAL` child-env stripping, error redaction, and `kill_on_drop(true)`.
- **NixOS `services.fabrico11y.remoteProxy`:** Added an opt-in
  `systemd-socket-proxyd` ingress/egress forwarder that keeps `fabric-server`
  and Spindle forwarding strictly loopback-bound while traversing private IPv6
  or WireGuard meshes using unbracketed `::1:<port>` targets.
- **Native Debian 12/13 `.deb` and portable Linux `.tar.zst` releases:** Built on
  Debian 12 (`bookworm`, `glibc 2.36`) alongside the Fedora RPM in a SLSA
  provenance-attested release pipeline, eliminating host-glibc `patchelf`
  bundling across Debian 12 and Debian 13 fleets.

## Release Artifacts & Verification

Each tagged release publishes:

- Fedora RPM (`fabrico11y-0.1.0-0.alpha.3.fc44.x86_64.rpm`)
- Debian 12/13 package (`fabrico11y_0.1.0-alpha.3_amd64.deb`, internal version `0.1.0~alpha.3`, `GLIBC_2.36` floor)
- Portable Linux `x86_64` tarball (`fabrico11y-0.1.0-alpha.3-x86_64-unknown-linux-gnu.tar.zst`)
- `SHA256SUMS` and `RELEASE-EVIDENCE.json`, all attested via `actions/attest-build-provenance`

Verify downloads before installing:

```sh
sha256sum --check SHA256SUMS
gh attestation verify fabrico11y_0.1.0-alpha.3_amd64.deb --repo kmosoti/FabricO11y
gh attestation verify fabrico11y-0.1.0-alpha.3-x86_64-unknown-linux-gnu.tar.zst --repo kmosoti/FabricO11y
gh attestation verify fabrico11y-0.1.0-0.alpha.3.fc44.x86_64.rpm --repo kmosoti/FabricO11y
```

See [Debian 12/13 setup](../../packaging/deb/README.md),
[Fedora RPM setup](../../packaging/rpm/README.md), and
[Nix installation](../../docs/nix-installation.md) for host configuration.
