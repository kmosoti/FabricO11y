# Phase-1 log-reader counterexample and repair

Status: local component repair checked; full phase-1 qualification remains pending. The independent Sol/high review on `src/alpha/log_source.rs` SHA-256 `2c7265fa3f0e865a54d5ed60ca922d6fd55d8f3a6ab8147140853eeebae095db` is retained unchanged at `target/alpha-log-review/results.json`. It identified two executable defects: a 262,154-byte line followed by `normal\n` left the cursor at zero in three passes, and an unwritten FIFO blocked `File::open` until the reviewer killed the child. Its `ok\npartial` then newline positive control passed.

The repaired reader persists one `skipping_oversize` bit with each committed cursor. Once a line exceeds 4 KiB, it records a gap and advances the offset through at most 256 KiB per pass; after restart it resumes discarding bytes until the newline and can then deliver the following line. A nonblocking open followed by a regular-file metadata check makes FIFO rejection prompt. The caller commits cursor and gap in the same batch as collected records; append failure leaves the earlier cursor authoritative.

The independent probe was copied to `target/alpha-log-review-repaired/` without changing its three assertions. Its scratch `Cursor` gained the new boolean field and its manifest gained the already pinned `libc` dependency needed to compile the path-imported reader. The original review and input files were preserved. `cargo build --offline --manifest-path target/alpha-log-review-repaired/Cargo.toml` exited `0` after the scratch lock was refreshed offline. The copied binary's `valid`, `oversize` and `fifo` commands all exited `0`: the valid cursors were 3 and 11; the large-line cursors were 262144 and 262162, with only `normal` delivered; the FIFO returned `InvalidInput` immediately under a 2 s timeout. The tracked [regressions](../../../tests/alpha_log_source.rs) include a bounded child-process FIFO test, resumed oversized skip and incomplete-line control; `cargo test --offline --locked --test alpha_log_source -- --nocapture` exited `0` with four tests.

This check covers one selected local file and regular-file enforcement. Rotation, truncation, byte-cap and full-spool behavior are separate node/journal tests; network delivery remains absent.
