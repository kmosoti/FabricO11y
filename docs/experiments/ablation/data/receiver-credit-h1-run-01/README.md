# H1 packet-slot raw run 01

The [experiment record](../../receiver-credit-h1-run-01.md) explains the registered workload, gates, result, and limits. The run was generated by `bash tools/bench/run_transport_h1.sh target/transport-h1/run-01` on 2026-09-26 local time. The command exited 0. [environment.txt](environment.txt) records the toolchain, host, source hashes, and exact invocation. Its experiment-document hash is the preregistered version before the results section was filled in.

Files:

- [summary.csv](summary.csv): 20 seed/variant aggregate rows.
- [bursts.csv](bursts.csv): 20,000 burst-peak rows.
- [messages.csv.gz](messages.csv.gz): deterministic gzip of 640,000 message-level rows; decompress to `messages.csv` to rerun the analyzer.
- [analysis.json](analysis.json): independent CSV checks and preregistered gates.
- [SHA256SUMS](SHA256SUMS): hashes of the original uncompressed run files under `target/transport-h1/run-01`.
- [PRESERVED_SHA256SUMS](PRESERVED_SHA256SUMS): hashes of the files preserved here.

`gzip -t messages.csv.gz` and a byte-for-byte comparison of its decompressed contents with the original `target` CSV both exited 0 before this copy was recorded. `sha256sum -c PRESERVED_SHA256SUMS` exited 0. The raw message file is compressed only to keep this text-based research record small; no rows were filtered.

To recheck the preserved CSV with the current analyzer from the repository root:

```sh
mkdir -p target/transport-h1/recheck
cp docs/experiments/ablation/data/receiver-credit-h1-run-01/{summary.csv,bursts.csv} target/transport-h1/recheck/
gzip -dc docs/experiments/ablation/data/receiver-credit-h1-run-01/messages.csv.gz > target/transport-h1/recheck/messages.csv
python3 -B tools/bench/summarize_transport_h1.py target/transport-h1/recheck > target/transport-h1/recheck/analysis.json
```

The checker validates identities, registered release ticks, timing lower bounds, ACK order, counts, fixed control overhead, caps, goodput, and decision gates. It cannot reconstruct every switch-queue peak without a per-tick queue trace. The Rust simulator has one analytic small-incast peak test; this limit is part of the [interpretation](../../receiver-credit-h1-run-01.md#interpretation-and-limits).
