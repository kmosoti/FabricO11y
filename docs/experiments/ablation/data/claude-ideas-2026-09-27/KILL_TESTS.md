## E1R — I7

Supersedes E1 before any run, following REVISION_REVIEW.md. Authenticated coverage with separate builder and receipt contracts. Fixed workload: four S1-shaped corpora (Gauge, clustered Logs, shuffled Logs, mixed), seeds 101,102,103, 2,048 events, block size 64, 128 queries per snapshot with PRNG seed 7. Query generation and oracle code must be frozen before evaluating candidates. Independent exact full-scan positional oracle, sharing no predicate or summary implementation with the candidate. Builder check: mutate each candidate summary to omit a known matching row token/time/tenant; trusted builder must refuse before sealing. Receipt check with valid builder output: inject omitted ordinal, stale summary, reordered ordinal, replaced externally trusted root, mismatched snapshot, truncated count; reject inconsistent receipts. An explicit unavailable disposition may be a valid receipt but must yield incomplete status, never an empty complete answer. Clean controls must verify, match full-scan positions, and include complete status only when every block is scanned or safely excluded. Receipt verification must read zero row bytes; builder validation may read rows. Separate trust-boundary negative control: deliberately bypass the builder to seal row=rare with summary=common, and trust that root. The row-free verifier cannot establish the semantic bug: the otherwise well-formed receipt passes, while the independent row oracle detects the wrong empty answer. builder_version only identifies code, never proves correctness. contract_violations counts deviations from these expected actor-specific outcomes, false rejections of clean controls, wrong clean answers and receipt row reads. Threshold <= 0. Mutation non-vacuity: original chain-only I1 must miss a replaced-root/omitted-ordinal fault; a builder missing the inclusion validation must accept the invalid summary, and the checker must fail each mutation. Assumptions: correct trusted builder, independently trusted immutable root/count, collision-resistant SHA-256, trusted exact non-malicious evaluator for scanned blocks. Scope: finite in-memory logical models; no adversarial execution proof, physical durability or performance claim.

## E2R — I8

Supersedes E2 before any run, following REVISION_REVIEW.md. One-sync group seal with explicit external failed-I/O authority. Workload: groups of 1..6 frames, generator seeds 11,12,13 and Log bodies 57..4096 bytes; sectors 512 and 4096 bytes. Freeze framing and oracle definitions before implementation. Enumerate every persisted sector subset for an in-flight group with <=16 sectors, otherwise 100,000 subsets with PRNG seed 5; earlier groups are ACKed. Also inject 1,000 covered-byte flips per seed in previously committed headers/payloads/seals and errors at each write/sync boundary. Independent allowed-outcome oracle: a valid full group is accepted; a plausible incomplete final tail without a complete seal may be truncated to the preceding committed prefix; a complete seal with mismatching content MUST fail closed with all bytes preserved. A seal-only persisted subset therefore errors, not truncates. Recovery may return a seal-aligned prefix retaining all ACKed groups or a fail-closed error preserving every byte; never expose a partial group or discard ACKed data. Clean full groups must be accepted, preventing an always-error implementation from passing. Detected post-ACK corruption must error without mutation. Write/sync error poisons the live handle and gives no ACK for that group. An external supervisor/caller records the error and forbids automatic resume, requiring an independent trusted source on healthy storage. The file format does not persist or infer that error witness: test identical valid bytes produced by successful-sync and EIO histories, require identical file-scanner output but different supervisor decisions when the external error flag differs. Without that witness, safe automatic resume after known EIO is outside the claim. contract_violations counts cases outside these outcomes; threshold <=0. Non-vacuity: truncate-on-mismatch mutation fails post-ACK corruption; always-truncate subset model fails seal-only subset; a file-only EIO detector fails the indistinguishable-history case; always-error fails clean controls. Assumptions: single writer, sector-atomic writes at stated sizes, honored successful file and directory sync, durable existing namespace, collision-resistant SHA-256, external retention of I/O-error knowledge. Scope: finite logical model, not device power-loss validation or unconditional media-corruption recovery. Register group-size-1 events/s, CPU and sync-count comparison separately after correctness passes; compare equal batching before exploring batching gains.

## E3R — I9

Supersedes E3 before any run, following REVISION_REVIEW.md. Snapshot-bound residual composition with explicit conflict rejection. Fixed workload: mixed and shuffled-Log corpora, seeds 201,202,203, 2,048 events, block size 64, 10% duplicate EventIds, 128 queries/snapshot with PRNG seed 9; 1,000 availability masks/snapshot with PRNG seed 7; 1..3 repeated retries, 50 successor snapshots with compaction/position reuse, and a permanently corrupt block in 5% of masks. Freeze generator and independent full-scan positional oracle before candidate evaluation. Residual binds independently trusted snapshot root, block ordinals and digests, exact predicate bytes, tokenizer and order versions. Each covered block has an exact predicate result from a trusted evaluator or valid conservative summary; result coordinates are (snapshot,block,row). Merge identical retry values once; compare complete canonical event bytes or authenticated row digest at duplicate coordinates and reject conflicting values, never choose silently. Inject at least one conflicting value at an existing coordinate for every snapshot/query, changed predicate/tokenizer/order bindings, cross-snapshot residuals and modified block digests. Closed answers must equal their own snapshot full scan in original arrival order, preserving distinct positions with equal EventIds. Unresolved corrupt/unavailable blocks remain explicit and prevent closure. Clean retries/merges must succeed. contract_violations counts wrong closed answers, duplicate physical emissions, accepted conflicts or binding mismatches, false closure, lost EventId-duplicate positions and rejected clean retries; threshold <=0. Non-vacuity: original unbound merge fails cross-snapshot case; first-value-wins mutation fails conflicting-coordinate case; EventId dedup mutation fails positional duplicate case. Assumptions: immutable retained snapshot identities/digests, trusted exact evaluator, trusted valid summary builder, collision-resistant authentication. Scope: finite in-memory model; no guarantee unavailable data eventually returns, no performance or cold-storage claim.
