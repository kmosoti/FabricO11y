# Historical hypothesis-study archive

This is a byte-for-byte selection from the completed external study at `/home/kmosoti/experiments/studies/2026-09-fabric-evidence-ideas`. [SHA256SUMS](SHA256SUMS) records the archived bytes; `manifest.json` records their original paths. It omits the literature embedding cache, downloaded literature, generated data directories and the larger linked working draft. [The repository summary](../../claude-hypotheses.md) is the navigable interpretation.

`IDEAS.initial.md` contains the original six proposals. `IDEAS.jsonl` retains their ledger entries and the later I7–I9 entries. `CRITIQUE.md` and `critique_probes.py` record six cross-family counterexamples; `REVISION_REVIEW.md` and `revision_probes.py` record four more. `KILL_TESTS.md` contains the amended E1R/E2R/E3R protocols; `FINAL_REVIEW.md` records conceptual approval. `CLAUDE_RUN.json`, `FINAL_CHECKS.json`, `PROVENANCE.json` and `LOG.jsonl` record the original invocation, final checks, Fabric revision and experiment registrations. The initial ideas were generated with Claude Opus; the independent conceptual critiques were GPT-family. The source study's `LOG.jsonl` records all six experiments as `not_run`: E1/E2/E3 were superseded before execution, and E1R/E2R/E3R were future plans at archival time. Later Fabric run records carry later outcomes; this historical ledger is deliberately unchanged.

Some copied prose mentions original absolute or repository-relative paths as provenance. The Markdown links in the copied reports resolve within this archive, except external web references. Original tool commands under `~/.claude/scripts/research` are context, not required to read or validate this archive.
