# Completion selector controls dispatch

Consolidate the three previously registered selector commands in one serial
coordinator job to avoid three copies of identical source/receipt overhead.
`coupled_completion_checks.py` first formats only four newly introduced/edited
Rust fixtures, then executes the unchanged library selector test at explicit
8,16,32MiB compile settings and records each command and exit. Stop on failure.
Frozen native O7/O8 executables retain their original archived identities;
formatting is not a claim that those binaries were rebuilt.

Run catalog-coupled-c5-selectors-01, preparation stage,180s,4MiB global reserve,
zero capacity reserve through resource_group/run_job/coupled_admit. This replaces
only the individual selector dispatch IDs from completion-controls registration,
not their tests, expected outcomes or scope. It is not a C5 service cell.
