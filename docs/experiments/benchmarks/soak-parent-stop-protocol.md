# Registered R3 final parent observation mode

Prospective registration, 2026-10-15; no execution or result claimed.
The [R3 exposure protocol](soak-protocol-r3.md) requires a final actual empty
whole-parent kernel observation. A vanished cgroup or completed child receipt
alone does not establish those fields.

An explicit `tools/resource_group.py --observe-final-group --delegate
--runtime-seconds 7500 -- COMMAND` mode keeps the exact owned service active
after its inside wrapper exits (`RemainAfterExit=yes`). The outside launcher
observes the independently supplied unit's systemd activation monotonic anchor,
ControlGroup, zero MainPID and exited substate. It authenticates the actual
inside completed receipt, command/unit/cgroup and exit; then holds the cgroup
directory, observes empty parent and every existing subgroup, and rechecks
directory identity/systemd state. The receipt is insufficient until the inside
wrapper really exited. The wrapper's kernel parent is distinct from this
outside observer. The default launcher command/behavior stays unchanged.

Read the complete R3 parent field set, exact 5/6 GiB high/max, tasks1536,
swapmax/current0, OOM/oom_kill0, charge/peak bounds, task counts and empty
population/process lists. Keep actual CPU/I/O and subgroup accounting too.
Record actual directory device/inode and integer monotonic observation bounds.
Do not accept removed/replaced groups, self-asserted fields or an empty parent
with missing subgroup observations. After capturing, stop this owned retained
unit and reap systemd-run; success requires its actual exit to agree with the
inside command's exit and confirmed service stop. The external receipt binds
the actual final kernel fields and activation anchor for later offline joins.

The one outer allowance remains7500 seconds from actual service activation;
observation grants no extra runtime or phase allowance. Every outside show,
read/poll, stop and transport wait is bounded. Missing/truncated receipt,
failed/early unit, remaining children, missing/read-failed kernel fields, changed
unit/cgroup identity, exhausted allowance or unconfirmed wrapper stop refuses
the trial and preserves evidence. Stop/kill cleanup after a failed bound is
reported as failed/forced cleanup, never a successful observed run.

Before implementation, finite controls register: default parsing unchanged;
mode without exact7500/delegation refused; complete actual-shaped empty fields
accepted; missing parent/subgroup/field, populated group, remaining PID,
nonzero swap/OOM, wrong cap/task bound and replacement directory refused.
Controller controls inject truncated receipt, an otherwise valid different-job
receipt, live inside wrapper despite completed receipt, early transport exit,
timeout, failed stop and changed activation/cgroup. These are finite source
controls, never real-kernel evidence. Separate native controls must run under
the unchanged default launcher before this mode can support S1/FULL.
