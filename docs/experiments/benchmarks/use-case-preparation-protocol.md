# Application and investigation fixture preparation protocol

Registered scope: validate the existing seven RCA fixture definitions and their
producer/query packet preparation while extending the use-case research design.
This is a finite fixture/validation task, not native RCA execution, a production
capability change or deployment qualification. Register this protocol separately
from code. The prior read-only preflight remains recorded with exit 2.

Use the existing pressure-round ledger, preserving every previous charge and
the 7,200-second round / 36,000-second frontier / 86,400-second campaign ceilings.
No new time allocation is granted. Admit each command separately; retain the
remaining pressure confirmation and final-check obligations. Parent containment
remains 16/20 GiB high/max with no swap and data-drive scratch. No Fabric server,
browser, remote workload or live Nomos integration runs in this preparation.

The first preparation job has a 60-second deadline and 8 MiB query-evidence
reservation. Its generator stages at most 1 MiB of documents plus manifest in
the launcher's owned data-drive temporary directory, copies authenticated small
evidence into the ledger's query category, and returns without retaining scratch.

Validate all fifteen encoded Batches by digest and independent decoding. Require
fourteen initial Batches and one late Batch; seven distinct scenario identities;
contiguous per-source sequences; seven playbooks with eight supported queries
each; investigator output containing no controller source/ground-truth files;
correct semantic metric units; root/child identities and the declared span
durations, including the two-second clock offset. Assert the known counter
example yields 6/s followed by a reset, and late evidence changes the expected
trace population only when that Batch is included. Missing instrumentation may
coexist with a complete retained scan; no causal inference result is graded here.

Run representative rejection controls against the preparation checker: mutate
payload bytes without updating the digest, remove a required initial Batch,
mislabel the late Batch as initial, and put a truth-bearing file in investigator
output. Each must be rejected. These are new fixture-checker controls, not changes
to the independent query/delivery oracles or their expected outcomes.

Record exact commands, exits, source/bundle hashes, observed resource use,
storage path and cleanup in the usual coordinator/launcher receipts. Run the
existing manual documentation profile under a separately admitted 60-second
job after reconciling the research documents; hooks and documentation CI remain
disabled. Any failure retains its original evidence and exit. Changed acceptance
rules require a separately registered revision; do not relabel an old outcome.

The check only establishes that synthetic packets and recipes have the intended
shape. It does not establish that Fabric ingests them, answers their queries,
supports browser intake, evaluates Nomos, or diagnoses any real incident.
