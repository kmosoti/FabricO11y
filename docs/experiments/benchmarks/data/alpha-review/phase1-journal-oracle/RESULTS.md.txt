## Findings and limits

No counterexample was found for the tested public API behavior. The tests exercised malformed metrics and logs protobuf inputs, an encoded batch over 1 MiB, and a full 8 KiB journal as deliberate negative cases; each was rejected without advancing observable committed state. Reopening preserved identity and next sequence, and a second live writer was excluded.

This result does not establish on-disk exact-byte replay, data/marker sync order, recovery-required authority after a known I/O error, partial-tail invisibility, FOL2 compatibility, server retry/dedup, or physical-power-loss durability. `README.md` lists the required external probes and seams. There were no performance measurements.
