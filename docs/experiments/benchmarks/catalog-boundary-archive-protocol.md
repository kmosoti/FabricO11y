# CQ1 archive admission amendment

Register before plain pairs 2 and 3. The frozen native binaries, fixtures, trial
order, all 64 full chains per trial and original performance guards are unchanged.
The [reviewed allocation](catalog-evidence-allocation-protocol.md) and
[lossless representation](catalog-evidence-compaction-protocol.md) apply.

`query_boundary.py --reuse-build` now shares the original diagnostic `objects`
directory through an explicit link. Existing retain-byte checks still compare
exact decompressed bytes before reusing a matching content key. Binary archive
paths are byte-verified hardlinks to the same frozen executables. Fully verified
closed trial JSON files of at least 1 MiB are compressed with exact readback and
incremental transformation receipts. No logical answer bytes are normalized.

Run the existing pair2/pair3 commands with additional `--cap-mib 1024
--reserve-mib 240 --account DIRECTORIES...`. Account for the diagnostic, all
previous pairs, metadata precursor, both preboundary build archives, canonical
pool and every compaction receipt directory. The current output and resolved
shared object directory are included automatically. Before admission require
240 MiB headroom for the next three-trial slice. Before each trial and after
closed-trial compaction, check both unique inode file lengths and allocated
blocks against 1 GiB. Report distinct logical path bytes without counting a path
twice when a nested directory is explicitly scanned. A changed driver never
rebuilds or changes the frozen native comparison executables.

The CQ1 summary reads original JSON or its exact gzip representation and derives
warm medians, pre-continuation HWM, paired ratios and unchanged guards from retained
raw timing lines. It requires all 18 trials and all 1,152 passed full-chain verdicts.
No partial slice establishes a completed comparison. Representation/accounting
failures remain failures, separate from the experiment's performance outcome.
