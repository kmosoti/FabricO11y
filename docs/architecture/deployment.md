# Planned Linux alpha deployment

Status: accepted phase-5 contract; no service unit or installer is implemented yet. The [alpha contract](../ALPHA.md#linux-installation-contract-phase-5-not-yet-implemented) owns the exact installed defaults and acceptance gates. The [current system](system.md) remains one local demo executable.

The package will run one native node and one central server as distinct systemd services. Both use the static `fabricolly` user and primary group. `fabricctl` is an operator CLI, not a daemon. The two services belong to `system-fabrico11y.slice`, a child of `system.slice`, so systemd can enforce their aggregate memory/task bound while each service retains its own limits. There are no other alpha services or delegated cgroup managers. [systemd resource control](https://manpages.debian.org/trixie/systemd/systemd.resource-control.5.en.html) defines the slice hierarchy and effective limits.

The vendor sysusers declaration owns identity creation, with administrator overrides in `/etc`; installation must reject an existing identity that fails the expected service-account checks. systemd owns runtime/state directories and cgroups. Root owns installed binaries, units and base configuration; the services get only required state and credential access. Narrow local ACLs authorize selected log files. The node reads host `/proc`, `/sys`, and `/sys/fs/cgroup` for the required host metrics, while neither daemon writes cgroup files or gains privileges on source failure. [sysusers.d](https://manpages.debian.org/trixie/systemd/sysusers.d.5.en.html) and [systemd.exec](https://manpages.debian.org/trixie/systemd/systemd.exec.5.en.html) define these mechanisms.

At install acceptance, check real effective resource controls and source visibility under the service sandbox, plus account collisions, directory modes, TLS, restart and retained data. A static unit check is only an early syntax gate. [ADR-0010](../decisions/ADR-0010-use-static-systemd-services-for-alpha.md) records why this is the alpha deployment boundary.
